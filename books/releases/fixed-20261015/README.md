# Проверенная дебютная книга от 2026-10-15

`depth12.book` — постоянная копия результата пятичасового обучения против
фиксированного исходного движка. Каталог разрешён для включения в Git; очистка
журналов эксперимента не затрагивает книгу. Исходная копия сохранена в
`logs/experiments/fixed-openings-20261015/depth12.book`.

Формат `AI_CHESS_BOOK 1`, 33 позиции, 50 ходов. SHA-256:
`37e7eb0f3bc26b75d0f7a3df4c72a10829825b75fb9b444b8e7e349c80c8f040`.
Проверенный движок: SHA-256
`b25d972aef0020f76c2c2bdca1f91cffff3fc3ac6d7f7ed819b6f92cc82306e6`.

Независимый финальный матч при 0,05 с/ход: 642 зачётные партии в 321 паре,
633 победы, 8 ничьих, 1 поражение, 99,22% очков. Результат относится к этому
сопернику и контролю. Другие соперники и контроли не проверены.

`comparison-metrics.json` сохраняет все итоговые показатели исходного summary.json
без списка отдельных партий; `independent-audit.json` — отчёт независимой проверки.
Полные PGN, исходные данные обучения и бинарники остаются в локальном каталоге
эксперимента. Подробности: `plans/04-learning.md` от корня проекта.

В текущем рабочем каталоге `books/default.json` переключён на эту копию. Сам файл
настроек локальный, игнорируется Git и содержит абсолютные пути. После клонирования
можно указать книгу явно в GUI или выполнить из корня проекта:

```bash
python3 -m ai_chess match --games 2 --time 0.05 --book books/releases/fixed-20261015/depth12.book
sha256sum books/releases/fixed-20261015/depth12.book
```

Сохранённую версию не перезаписывать результатами новых экспериментов: создавать
отдельный каталог выпуска и заново проверять качество.
