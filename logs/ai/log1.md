- ai_chess/qt_runtime.py проверяет Qt до создания виджетов, запрещает запуск несовместимых bindings или переключает CLI-запуск GUI на проверенное .venv. Не изменять refcount Python вручную и не маскировать проблему удержанием None.

### Исправление none_dealloc после пользовательской проверки
Пользователь подтвердил работу GUI, но сообщил об аварийном завершении в paintEvent/drawText. Без GUI воспроизведено уменьшение refcount(None) на каждом вызове void-методов Qt под Python 3.10.12. Например, 100 QObject.setObjectName дают дефицит 100 ссылок. В официальных заметках Qt описана проблема ABI INC/DECREF при сборке на Python 3.12 и запуске на 3.10 (PYSIDE-3424): https://wiki.qt.io/Qt_for_Python_Development_Notes.

Уже установленный Python 3.12.15 использует те же пакеты abi3 корректно: 50000 вызовов QtCore/QtGui не меняют refcount(None). Создано .venv без pip со ссылками на существующие пакеты. Добавлен воспроизводимый offline-скрипт tools/create_gui_env.py, проверка ai_chess/qt_runtime.py и автоматическое переключение обычной команды GUI на .venv. Существующие зависимости и C++-код не изменялись.

17 Python-тестов проходят (2.46 с). Агент не создавал окон и не выполнял визуальную проверку. Пользователь затем повторно сыграл полную партию и подтвердил победу компьютера без сообщения о повторном падении.

### 2. Пользователь — 2026-10-14T18:02:57.598Z

Надо сделать программу играющую в шахматы. Пускай она состоит из двух частей. Программа на python будет визуализировать шахматную доску и запускать одну или две программы на C++, которые будут играть в шахматы.
