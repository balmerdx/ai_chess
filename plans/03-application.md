# Сессии 3–4: контроллер, CLI и GUI

Статус: реализовано и проверено пользователем. После исправления несовместимости Qt/Python полная партия завершилась победой движка без сообщённого падения.

- Общий Game-контроллер; только он принимает проверенные ходы и определяет исход.
- Пакетные серии со сменой цветов и защитным пределом; технические поражения и диагностика.
- Атомарные PGN после каждого хода, метаданные времени и интерактивный просмотр.
- PySide6: игра мышью, превращение, наблюдение/пауза, список ходов, просмотр/автовоспроизведение.
- Рабочий поток выполняет поиск и запись. Новые поколения партии игнорируют старые ответы; закрытие дожидается сохранения без блокирующего GUI wait.
- Отклонение от исходного плана: собственный транспорт UCI по каналам вместо SimpleEngine. Причина — socket.send запрещён песочницей, а SimpleEngine требует его для пробуждения asyncio.

После приёмки обнаружен none_dealloc в paintEvent. Установленная сборка PySide6 6.12.0 теряет ссылки на None под Python 3.10 даже в простом QObject.setObjectName. Подготовлено локальное окружение Python 3.12 с теми же библиотеками, добавлены ранняя проверка и автоматическое переключение GUI. Воспроизведение и регрессионная проверка Qt выполнены без окна.
