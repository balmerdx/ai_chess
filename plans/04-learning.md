# Сессии 5–6: дебютная книга и окончания

Статус: реализованы первые версии; качество эвристик требует дальнейших измерений.

- Только собственные законченные партии двух движков; исключить технические поражения, человека и незавершённые игры.
- Python проверяет PGN и экспортирует ходы; C++ самостоятельно проверяет последовательности и строит статистическую книгу до 20 полуходов.
- Версионированный формат, статистика с точки зрения ходящей стороны, взвешенный выбор и seed; затем обычный поиск.
- Простые окончания: активный король и проходные пешки; для ладьи/ферзя против короля — край доски, расстояние между королями и уменьшение доступного прямоугольника.
- В quiescence простых окончаний разрешены два дополнительных тихих шаха: без этого на малой глубине возникали повторения вместо мата.
- Проверки: сборка/подключение книги, доведение контрольных ладейного, ферзевого и пешечного окончаний.

Будущие этапы: разнообразие собственных партий, более широкая выборка окончаний и точные таблицы. Текущие эвристики не дают гарантии идеальной игры во всех окончаниях.

## Адаптивный эксперимент 2026-10-14

Пользователь утвердил 40 минут адаптивного обучения и 20 минут независимой проверки. Обучение только по собственным законченным партиям двух движков. После поражения — однократное переключение на допустимую альтернативу; запрет не постоянный. Стандартная книга меняется только при подтверждённом улучшении.

Реализация: `train-book --adaptive`, `--opening-plies` (по умолчанию 12), `--opening-top` (8), `--history`. На каждом исследуемом полуходе свой поиск глубины 3 оценивает легальные продолжения, остаются до восьми лучших в пределах 50 cp; матовые исходы не смешиваются. Ключ статистики — доска, очередь хода, права рокировки и легального взятия на проходе, без номеров ходов. Одинаковая позиция через перестановку ходов использует общую статистику.

В каждой позиции сначала выбираются неиспытанные допустимые ходы. Для испытанных используется `(W + 0.5D + 1)/(n + 2) + 0.35*sqrt(ln(1 + N)/(1 + n))`, где `N` — сумма испытаний текущих допустимых кандидатов до одноразового исключения. Равенство разрешается seeded RNG. Это экспериментальная эвристика баланса исследования и использования опыта, а не гарантия оптимальности при меняющемся сопернике.

После независимой проверки законченного PGN статистика первых 12 полуходов обновляется с точки зрения сделавшей ход стороны. У проигравшей стороны первая исследованная позиция с альтернативами получает одноразовое исключение выбранного хода на следующее посещение. Если исключение нельзя выполнить безопасно, ход остаётся доступным, исключение ожидает следующей возможности. Новый проигрыш в этой позиции заменяет ожидающее исключение. `learning.json` атомарно сохраняет статистику, счётчики и исключения; `OpeningLearner.load` позволяет восстановить снимок. Возобновление оборванной серии через CLI не добавлено.

История берётся из прежнего учебного прогона при совпадении хешей обоих движков и времени на ход. Только PGN с `Experiment=training`, собственным происхождением и настоящим шахматным окончанием; полные последовательности истории дедуплицируются. История не создаёт ожидающих исключений. `history-games.txt` содержит учтённые партии, manifest фиксирует хеши источников. Они добавляются к новому экспорту для сборки книги; новые фактические партии учитываются независимо, в том числе повторные. Импорт из завершённой адаптивной серии переносит её PGN, без автоматического рекурсивного импорта её истории.

Сборщик C++ получил необязательные фильтры `--max-plies`, `--min-games`, `--score-margin`. Для эксперимента: 12, 6 и 0.05. Сначала исключаются недостаточно проверенные ходы, затем остаются ходы со сглаженной долей очков `(W + 0.5D + 1)/(n + 2)` в пределах 0.05 от лучшего. Формат и UCI не меняются; вне книги обычный поиск. Прежняя команда без фильтров сохраняет все прежние записи.

Команда `python3 -m ai_chess.learning_experiment --logs logs/experiments/adaptive-openings-20261014 --history logs/experiments/openings-20261014/training` сохраняет бинарники/хеши, проводит 2400 секунд само­игры при 0.05 с на обычный ход и пределе 400 полуходов, строит и замораживает книгу, проводит 1200 секунд парного сравнения с исходным движком без книги. Seed обучения 20261014; сравнения 21261014. Исследование входит в бюджет; подготовка и построение книги вне него. При технической ошибке эксперимент прекращается; прерванные таймером партии исключаются. Подключение — по прежним критериям из раздела выше.

Этап реализации завершён: 34 Python-теста, CTest Debug и ASan/UBSan прошли внутри песочницы с `detect_leaks=0`. Новые проверки покрывают переключение/возврат ходов, сохранение статистики, цвета/ничьи, происхождение и дубли истории, классификацию матовых оценок, доступность классических первых ходов, фильтры сборщика и реальную остановку адаптивного поиска.
