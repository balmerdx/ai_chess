# План ai_chess

## Архитектура
C++23: самостоятельное ядро правил, оценка, negamax/alpha-beta, итеративное углубление, quiescence, таблица транспозиций и UCI. Битовые доски и массив клеток, компактные ходы, обратимое применение без выделений памяти в узлах. Python: PySide6, python-chess, общий контроллер GUI/CLI, независимая проверка ходов, PGN и просмотр.

## Этапы и критерии завершения
1. [x] Каркас и документация — CMake Debug/Release с clang++-20, CTest, Python-пакет, команды запуска.
2. [x] Ядро — FEN, все легальные ходы, make/unmake, окончания, perft и независимая сверка.
3. [x] Поиск и UCI — ограничения времени/глубины, stop, Hash, info, совместимость python-chess.
4. [x] Контроллер и CLI — серии, чередование цветов, технические поражения, атомарные PGN после каждого хода.
5. [x] GUI — игра мышью, наблюдение/пауза, просмотр PGN; пользователь подтвердил корректность функций.
6. [x] Стабилизация без GUI — интеграционные проверки, ASan/UBSan без проверки утечек, Release-измерения, инструкции.
7. [x] Дебюты — экспорт проверенных собственных партий, C++-сборщик книги, статистика результатов, первые 20 полуходов, seed.
8. [x] Окончания — оценка ферзь/ладья против короля и пешечных окончаний, тесты доведения контрольных позиций до результата.

Нумерованные планы: 01-foundation.md, 02-engine.md, 03-application.md, 04-learning.md. Пользователь подтвердил работу GUI и после исправления none_dealloc сыграл полную партию: движок победил матом. Первая версия принята. История сессии и справка для продолжения: ../logs/ai/log1.md.

## Поведение
По умолчанию 1 секунда на ход. Время и глубина настраиваются. Ничьи по повторению/50 ходам автоматические. CLI ограничен 400 полуходами (результат * при достижении). Ошибка движка после старта — техническое поражение. Журналы содержат начало, часовой пояс, участников, лимиты и причину окончания. GUI не блокируется расчётом; запоздалые ответы прошлой партии игнорируются.
